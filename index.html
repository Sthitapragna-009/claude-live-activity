Touch and hold the island to expand it. Tap it to open the app. Pull down the Lock Screen card to see steps and controls. Push it up to close. At 68%, Claude Code asks permission to run tests. The island expands as an alert.

Every presentation, the same moment

These are the presentations Apple requires, tied to the same live state as the phone. Leading and trailing views read as one piece of information, and Clawd keeps the same place as the island grows.

Clawd's states

Each task phase gets its own small pixel-scale motion, so the state is readable even at 28pt in the island. Loops run only while work is happening, and all motion stops under Reduce Motion.

HIG rules this design follows

From Apple's Live Activities guidance (updated 13 October 2026), and how each rule shapes this concept.

Clear start and end, under 8 hours

Starts when you send a long task. When the task ends, the island clears right away, and the Lock Screen summary stays for 30 minutes.

Best practices
Black island, bold brand color

The island stays opaque black. Clay orange carries the identity and also marks the state: amber means Claude needs you, green means done.

Choosing colors
Compact reads as one unit

Clawd sits on the leading side and a progress ring on the trailing side, both snug to the camera and matched in size. Both open the same task screen.

Compact presentation
Minimal shows live data, not just a logo

The detached bubble wraps Clawd in a progress ring. At 28pt in limited width, it still shows progress.

Minimal · limited width
Expanded keeps the compact layout

Clawd and the time stay at the edges, and the track appears below them. The height is 156pt, inside the 84–160pt range.

Expanded presentation
One control, or a response

While running, the island has one control: Pause. A permission request is the exception, since you can act on it with Allow or Deny.

Offering interactivity
Alert only when essential

Only two events expand the island on their own: a permission request and completion. Step changes update quietly.

Starting, updating, ending
No sensitive content

Shows the task name, phase and counts. Code, prompts and file contents never appear on the Lock Screen.

Best practices
Animations under 2 seconds

Morphs take 300ms, content fades take 150–200ms, and the done hop runs twice and stops. Nothing animates on the Always-On display.
